07 · Way to build

Our neural networks decide. The LLM only talks.

InputTrooCore dataEvery data point, cleaned and with full history
DecidesNeural networksOur own models choose what goes into each plan. Tested before release, versioned and monitored.
OutputDaily planApproved by expert guardrails
TalksLanguage modelExplains the plan and answers questions. It never decides, because it can sound right and still be wrong.
SeesThe userA plan with a clear "why this"
How the models learn
01Start from expert knowledge

Trained first on curated reference data and guidance from your experts, so outputs are sound from the first release.

02Learn from every user

Retrained on anonymised data as profiles build up history, getting more personal over time.

03Tested before they ship

Every version evaluated on held out cases, monitored in use, and rolled back if it underperforms.

08 · Our recommendations

What we recommend, to build what you want to build

01
Build TrooCore before the screens

Decide how every data point is stored first, so later phases plug in without rework.

05
Test every API first

Sample data and accuracy checks before building on any vendor.

02
Make data points customisable

Markers, ranges, sources and rules managed from the admin console.

06
Keep the tone in check

Out of range markers read as worth attention, never as alarms.

03
Let neural networks decide

The LLM only explains and converses.

07
Health Connect and one aggregator

Google Fit APIs are deprecated. One aggregator covers the cloud wearables.

04
Keep every vendor replaceable

Each API behind its own connector. Change a vendor, nothing else moves.

08
Shopify store, privacy built in

Your existing store, India hosting, consent per data type, DPDP Act aligned.
